設定

トークンはこのブラウザの localStorage にのみ保存されます。各データベースは、Notion側で「接続」からこのインテグレーションに共有してください。

GitHub Pagesで使う場合は必須です(Cloudflare WorkerのURL)。ローカルのserver.jsで使う場合は空欄で構いません。

データベース

データベースID または Notion の URL を貼れます(データソースIDも可)。色は表示色です。「Todo」にチェックしたデータベースは、ノートを1件ずつ出さず、期限が今日以前の未完了タスクをまとめたTodo用カードを1枚表示します(「今日」表示のときのみ)。
